## 四、为什么 AUC 低于 0.5

模型没有使用完整的五级量表：**78 次输出里 `decide` 与 `act` 均为 0**，只用了 `none / monitor / investigate`。

| 模型输出 | 典型条目 | 人工标签 |
|---|---|---|
| `investigate` | NVIDIA 产品稿、英国犯罪统计附表、刚果埃博拉、曼联新闻 | 多为**弱**或**噪声** |
| `monitor` | ONS 零售销售、员工薪酬、时间使用调查 | 多为**可行动**（宏观决策依据） |
| `none` | 美联储终止执法行动、自然纪录片 | 弱 / 噪声 |

即：模型把"文中出现可核查的主张"当成 `investigate`，把"例行统计发布"降为 `monitor`；
而本轮人工标签把 ONS 的零售销售与薪酬发布视为可行动信息。两者的构造不同：

- 字段定义问的是"读者现在能做什么"（act/decide 导向）；
- 第二轮人工标签问的是"是否值得进一步调查或用于判断"（investigate 导向）。

这不是可以靠调阈值修正的偏差；继续加权重只会把方向错误固化。

## 五、结论（按预注册规则）

| 规则 | 结果 |
|---|---|
| 三轮方向一致 | 是（均 < 0.5） |
| 合并 AUC ≥ 0.70 | 否（0.388） |
| 至少两轮 CI 下界 > 0.5 | 否（三轮上界均 < 0.7，下界 < 0.2） |
| **判定** | **不纳入评分；本轮不支持进一步评估纳入资格** |

`actionability` 继续保留为**只记录、不参与**的字段。**没有**修改任何评分权重、证据门槛、通道或配额；
**没有**修改人工标签。

## 六、下一步建议（新实验，不并入本轮）

1. **先固定目标构念**：如果目标是"值得跟进"，字段应命名为 `follow_up`，枚举围绕"核查/数据/访谈"；
   如果目标是"现在能行动"，则人工标签必须按"可执行动作"重新定义。两者不能混用。
2. **新标签需要独立盲评**，不能复用本轮标签去拟合新字段。
3. **失败案例单独跟踪**：2 条条目在所有轮次均因 `category` 非法失败，应作为模型输出可靠性问题处理，
   不应通过放宽 schema 消除。
4. 在构念与标签确定前，不建议再做多轮调参；当前证据已足够说明"字段本身可用，但语义与目标不一致"。

## 八、限制

- 正样本只有 5 条，CI 很宽；结论是"在当前标签定义下不可用"，不是"actionability 永远无效"。
- 单一评审者、单日样本；标签基于摘要而非全文。
- 模型从未输出 `decide`/`act`，无法判断这两个层级是否可区分；这是量表设计或提示词的问题，需在新实验中单独验证。
- 本轮总分与 importance 的 AUC 来自提示词 v4 的重新分析，不能与第二轮 v3 的历史分数直接比较。

## 九、冻结与正式判定（2026-10-23）

**E2 结束。** 不再调参，不修改人工标签，不创建 `follow_up` 字段，生产评分保持原样。

| 判定维度 | 结果 | 依据 |
|---|---|---|
| 实验执行与审计 | **PASS** | 固定池、三轮、原始输出与解析结果留档、哈希可复核、凭证扫描 0 命中 |
| 工程兼容性 | **PASS** | 缺失/非法字段不致命；历史记录可重放；378 项测试通过 |
| 生产隔离 | **PASS** | 评分、证据门槛、通道、配额未改动 |
| 字段作为评分信号 | **FAIL** | 合并 AUC 0.388；三轮均低于 0.5；Top-13 可行动 2 vs importance/总分各 5 |
| 对其他语料的普遍结论 | **NOT_ESTABLISHED** | 正样本仅 5 条、单一评审者、单日样本 |

两点必须保留：

1. **反向区分不等于已证明模型普遍反向。** 正样本只有 5 条，CI 为 0.118–0.653；只能说"在当前标签定义下不可用"。
2. **`decide` / `act` 从未出现（0/78）**，五级量表退化为三级。若未来重定义目标，必须单独检查模型是否能区分层级，
   不能只看合并 AUC。
