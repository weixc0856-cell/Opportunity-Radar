# R2 第三批（契约 r2-v2、影子可靠性、扩大语料、冲突与审计完善）— 验收记录

日期：2026-11-01
状态：v7 仍为影子；核验规则 `r2-v1` 未改；生产提示词（v6）、评分与发布门禁未动。

---

## 1. 契约 r2-v2

| 变更 | 内容 |
|---|---|
| `revision` 词表 | 增加 `advance_estimate`、`final`（BEA 等机构真实使用的发布阶段） |
| `period` 格式 | 增加年度区间 `YYYY-YYYY`（如 `1997-2024`） |
| 原始表达留存 | 新增 `unit_raw` / `period_raw` / `revision_raw`，规范化值与模型原话并存 |
| 分隔符归一 | `Advance Estimate` / `advance-estimate` / `advance_estimate` 视为同一项 |
| 契约版本记录 | 每次核验写入 `claim_verifications.contract_version`（本批为 `r2-v2`） |

规则版本 `r2-v1` 未变；本批只扩展了契约词表与存储，不改判定逻辑。

## 2. 影子运行可靠性

- 影子改用分析器自身的 `analyze()`：解析失败会触发一次重排重试，与生产路径一致。
- Token 预算提高到 2400 并记录；记录 `model_calls`、`attempts`、`recovered`、`first_call_parsed`。
- 不复用、不覆盖任何 v6 结果：影子只读文章元数据，写入独立 JSON 目录。

## 3. 扩大语料：20 篇代表性文章

按来源均衡取样（每源最多 3 篇），覆盖官方统计、企业公告、新闻、论坛与观点：

| 项 | 结果 |
|---|---|
| 文章 / 成功 | 20 / **20**（0 失败，0 次重排恢复） |
| 耗时 | 1,716.8 秒（约 86 秒/篇） |
| Token 预算 | 2400，模型调用 20 次 |
| v6 事实 / 可定位 | 57 / 52 |
| v7 事实 / 可定位 | 71 / 65 |

### 3.1 字段完整率（31 条主张）

| 字段 | 条数 |
|---|---|
| 数值 | 16（51%） |
| 单位 | 8（25%） |
| 期间 | 10（32%） |
| 比较口径 | 2（6%） |
| 引文可定位 | 30（**96%**） |
| 数值+单位+期间齐全 | 8 |

- 契约偏差 4 条，全部是 `comparison: "monthly_rate"`（词表未覆盖，语义合理）。
- 单位出现 `%` 与 `USD`；类型 `fact` 30、`forecast` 1。
- **关键数字覆盖**：正文中带单位的数字 11 个，被主张覆盖 3 个（27%）。

### 3.2 核验结果（把影子主张写入临时库后运行）

| 状态 | 条数 | 说明 |
|---|---|---|
| verified | 3 | BEA GDP 两条 + 一条完整结构化主张 |
| rejected | 5 | 全部来自 BEA 个人收入：模型把 `$54.5 billion` 写成 `54.5 USD` |
| unverifiable | 23 | 15 条无任何可核验字段，8 条有数值无单位 |

**5 条 rejected 是本批最有价值的发现**：模型丢失数量级（billion），核验按"数值不在引文中"正确拒绝。
这不是核验误判，而是数值语义核验抓到了真实错误。

### 3.3 修复与确认运行

提示词增加规则："正文给出数量级时必须保留在单位里：`$54.5 billion` 是 value 54.5 + unit `USD billion`，
不是 54.5 USD，也不是 54500000000。"

用 3 篇 BEA 文章复跑确认：

| 项 | 修复前（同一批 BEA 文章） | 修复后 |
|---|---|---|
| 主张 | 5（其中 5 条被拒） | 5 |
| 数值 / 单位 / 期间 / 比较口径 | 5 / 0 / 0 / 0 | **5 / 5 / 5 / 5** |
| 契约偏差 | 4 | **0** |
| 核验 verified | 0 | **5** |
| 关键数字覆盖 | — | 5 / 8（62%） |

出现过的单位：`%`、`usd billion`。3 篇中 1 篇（个人收入，数字最密）两次输出都在 2400 tokens 处截断，
重排恢复也失败——这是需要提高预算或拆分输出的实证。

## 7. 限制

1. v7 未启用；生产仍为 v6。
2. 关键数字覆盖率 27%（修复后局部 62%），多数带单位的数字仍未被主张捕获；与"每篇最多 6 条主张"的上限有关。
3. 长文（数字密集）在 2400 tokens 处截断；需要更高预算或分段。
4. 20 篇样本仍不足以给出字段准确率，只能说明方向。
5. `comparison` 词表未覆盖 `monthly_rate` 一类表达，需在 G6 决定映射还是扩词表。

4. 「有数值无单位 → unverifiable」继续维持。
