# 第二轮对照实验设计（预注册）

> 本文件在运行前固定参数与判定规则，避免看到结果后再挑指标。
> 第一轮（`docs/E2E_SOURCE_QUALITY_2026-10-23.md`）已完成并冻结；本轮不从它的数据里取任何样本。

## 一、目的

回答三个问题，且只回答这三个：

1. 在**同一时间窗口**内，官方/新闻组是否比社区组覆盖更多情报主线？
2. 这种覆盖是否伴随**可行动信息**的增加，还是只是例行发布变多？
3. 两组在**分析失败率**与**证据定位率**上是否可比？

不回答：来源是否权威、许可是否允许、长期是否稳定（这些另行验证）。

## 二、预注册参数

## 三、盲评协议

人工判断是第一轮的弱项（单人、非盲）。第二轮固定如下：

1. 从每组的 items.json 导出 `title + summary_zh + evidence_rank`，**去掉来源名、URL 与组标签**，随机排序（用固定随机种子，种子写入报告）。
2. 评审者按三档标注：**可行动 / 弱 / 噪声**，定义与第一轮相同。
3. 标注完成后再揭盲，按组汇总。
4. 记录标注耗时与不确定项；不确定项单列，不计入任何一档。
5. 仍然只有一个评审者——这能消除"知道来源"的偏差，但不能消除个人标准偏差；结论必须这么写。

## 四、判定规则（运行前固定）

| 问题 | 判定 |
|---|---|
| 主线覆盖 | 候选组覆盖 ≥4 条主线且基线 ≤2 条 → 支持 H1；否则不支持 |
| 可行动比例 | 候选组可行动比例 **≥** 基线组 → 支持"覆盖提升没有牺牲行动性"；低于则明确写"否" |
| 证据 | 两组 E2 都按实际统计；候选 E2 仍为 0 时，结论必须是"E2 缺口未解决"，不得用 E1 数量替代 |
| 失败率 | 分析失败 >10%（任一组）时，先排查模型输出合规性，再解读内容差异 |
| 样本不足 | 任一组窗口内 <30 时，只报告实际数，并声明组间不可比的部分 |

**不允许**：看到结果后更换窗口、换指标、剔除"异常"条目、把 FAIL 改写成 PASS。

## 五、必须产出的指标

与第一轮一致，另加两项：

- 来源健康度：每源条目数、正文中位、空正文率、最新条目、**本轮窗口内可用条目数**；
- 情报覆盖：9 条主线条目数（含 0 的条目）；
- 证据：E0/E1/E2、定位率、正文依据；
- 信息价值：可行动/弱/噪声、跨来源同事件键（仅作线索，不是转载识别）；
- 管道：分析成功率、失败类型（schema / 超时 / 网络）、过滤原因、`deferred`、耗时；
- **新增**：每源窗口内条目占比（检验"取数池 200"是否足够）；
- **新增**：两次运行之间条目的重叠情况（同 URL / 同标题），用于判断窗口是否稳定。
