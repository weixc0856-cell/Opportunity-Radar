# Opportunity Radar 测试计划与发布门槛

## 1. 已完成的基线检查

在用户上传的 ZIP 解压副本中执行：
`python -m unittest discover -s tests -v`

结果：140 tests passed。该测试只覆盖仓库已有测试范围，不代表真实服务已连接。

## 2. 测试层级

### 单元测试
- 来源审核与来源准入
- Feed ID 映射和重复检测
- LLM JSON schema 验证
- 引文可定位性
- 评分权重与阈值
- SQLite schema 迁移、历史记录和幂等
- 收件人解析与去重
- 邮件安全模式选择

### API 集成测试
- 所有路由的正常返回与错误返回
- 请求体格式错误、字段缺失、超大请求体
- 非本地 Host/Origin 的写请求被拒绝
- 不能通过 API 读取秘密值
- CSV 保存失败、并发保存、重复 source_id
- FreshRSS API 超时/认证失败
- SMTP 认证失败、收件人拒绝、部分成功

### 前端交互测试
- 初次加载和服务离线状态
- 来源搜索、筛选、编辑、保存、审计
- 启用未批准来源时显示可读阻断原因
- 多邮箱添加、去重、格式错误和保存
- 测试邮件提交状态与部分失败状态
- 运行中重复点击被禁用
- 定时任务注册成功/失败反馈
- 日志为空、报告不存在、接口错误
- 键盘导航、Escape 关闭 Modal、焦点管理、窄屏表格

### 端到端 smoke test
1. FreshRSS 可访问且认证成功。
2. Feed 列表与登记表映射正确。
3. 本地 `/v1/models` 可访问。
4. 本地模型完成一次结构化分析。
5. SQLite 写入文章、分析和运行记录。
6. HTML/TXT 报告生成且包含原文链接。
7. 163 SMTP 向测试邮箱提交邮件。
8. Windows 计划任务可以启动并写入日志。
9. 重复运行不会重复投递同一报告。
10. 模型或 SMTP 失败时产生正确状态与日志。

## 3. 故障注入清单

- FreshRSS 服务关闭
- Fever API Key 错误
- 模型服务关闭
- 模型超时
- 模型返回无效 JSON
- RSS 文章无摘要或日期格式错误
- SQLite 文件只读或锁定
- 报告目录不可写
- SMTP 密码错误
- 第一个收件人成功、第二个失败
- Docker Desktop 未启动
- Task Scheduler 注册失败
- 后台服务在任务运行期间退出
- 磁盘空间不足

## 4. 发布门槛

- 140 项现有测试继续通过。
- 新增的 API/前端测试通过。
- 至少一次完整 smoke test 成功。
- 至少一次故障注入确认错误可定位且不会伪造成功。
- 日志中无授权码、API Key 或认证头。
- 来源审核状态、分析结果、报告内容和邮件内容一致。
- 所有展示样例明确标注真实/示例。
